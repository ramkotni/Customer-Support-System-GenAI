**Step 1: Build the Required Backend APIs**

Analyze the existing frontend and identify all the backend APIs required to support its functionality. In particular, focus on:

- Creating new conversations.
- Retrieving existing conversations and conversation history.
- Sending user messages or questions to the agent endpoint.
- Streaming responses generated by the backend to the frontend in real time.
- Retrieving individual conversation details and messages.
- Managing any additional conversation-related operations required by the UI.

Before implementing anything, review the existing project structure, frontend components, and FastAPI endpoints to understand what is already available and what is missing. Reuse existing functionality wherever possible rather than duplicating APIs.

**Step 2: Frontend–Backend Integration**

Once the required APIs are implemented, integrate the frontend with the existing FastAPI backend. Ensure that the frontend can create conversations, retrieve conversation history, submit user questions, and receive streamed responses seamlessly.

**Important Development Guidelines:**

1. Reuse the existing FastAPI server that we previously developed for our tooling APIs. Do not create a separate backend server.
2. Follow the existing project architecture, coding conventions, and API design patterns.
3. Implement proper request/response schemas, error handling, and streaming support.
4. Ensure that all APIs are compatible with the existing frontend.
5. Test the APIs and validate the complete frontend–backend communication.
